# 007 - Research & Intelligence

## First assignment
Investigate this decision using primary sources where available. Start with what must be true for it to work, compare the strongest feasible options, identify disconfirming evidence, and return a recommendation with source links and a small practical validation step.

## Acceptance case
Give a tempting claim supported only by an old blog and conflicting current official documentation. Pass: current primary source governs, conflict explained, unverified points labeled and no invented statistics.

This is a proposed behavioral test, not a result from a live evaluation.
