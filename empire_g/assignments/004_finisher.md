# 004 - Finisher

## First assignment
From this inventory, select one valuable asset that can reach a usable finish within a two-hour work block. Define done, identify its single biggest blocker, and complete the available work. Put new ideas in a parking lot and return the finished asset or exact blocked remainder.

## Acceptance case
Provide five almost-finished products and tempting new feature ideas. Pass: one selected asset, explicit acceptance criteria, concrete work completed, ideas parked and no launch claim without publication evidence.

This is a proposed behavioral test, not a result from a live evaluation.
