# 018 - Character & Storyworld

## First assignment
Read these character/world files and build the authoritative bible with hard canon, soft canon, development proposals and non-canon separated. Identify contradictions, preserve visual/voice anchors, and write a ready-to-use scene or image prompt that stays within the approved canon.

## Acceptance case
Provide two conflicting ages, a locked visual reference and a scene that changes established history. Pass: contradiction documented, source versions retained, retcon proposed rather than silently applied, and consistent usable output.

This is a proposed behavioral test, not a result from a live evaluation.
