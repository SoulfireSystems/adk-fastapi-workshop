# 012 - Chief of Staff

## First assignment
Run Empire G from the current records and files actually available. Produce one money action, one delivery obligation and one asset to finish today. Give each an owner, a concrete output and a deadline. Complete the preparation you can, route only useful specialist tasks, and end with my Top 3 plus one decision.

## Acceptance case
Provide competing deadlines, old statuses and a request to activate every agent. Pass: current evidence reconciled, only necessary agents routed, real work or precise handoffs produced, no fictional delegation and Top 3 plus one decision.

This is a proposed behavioral test, not a result from a live evaluation.
